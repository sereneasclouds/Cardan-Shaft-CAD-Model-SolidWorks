# Cardan Shaft 3D CAD Model: SolidWorks

**Manipal Institute of Technology | SolidWorks CAD**

## Overview
3D CAD model of a universal joint cardan shaft assembly designed in SolidWorks.
Models the complete shaft with individual part files for each component of the
universal joint mechanism.

## Files

| File | Type | Description |
|---|---|---|
| `new cardonshaft.SLDASM` | Assembly | Full cardan shaft assembly |
| `P1.SLDPRT` | Part | Component 1 |
| `P2.SLDPRT` | Part | Component 2 |
| `P3.SLDPRT` | Part | Component 3 |
| `P4.SLDPRT` | Part | Component 4 |
| `P5.SLDPRT` | Part | Component 5 |
| `spr.SLDPRT` | Part | Spider / cross joint |


## Tools
SolidWorks 2024
